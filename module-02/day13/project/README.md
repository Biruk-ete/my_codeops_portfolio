# Bole Brew Café Card

A simple business profile card for **Bole Brew Café**, a cozy coffee shop located in Bole, Addis Ababa.

# CSS Techniques Used

- CSS custom properties (`:root` variables) for colors, spacing, and border radius.
- Global `box-sizing: border-box` for predictable sizing.
- Google Fonts integration using the **Inter** font family.
- Box model styling with padding, margin, border, and border-radius.
- Centered card layout using automatic margins.
- Typography hierarchy using different font sizes and weights.
- HSL color values for theme colors and hover effects.
- Button hover state with a lightness change.
- Pseudo-element (`::before`) for a decorative coffee icon.
- Responsive image styling with `width: 100%`.
