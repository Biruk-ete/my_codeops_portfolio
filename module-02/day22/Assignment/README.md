Birr Watch - Currency Converter

- A simple web-based currency converter that tracks exchange rates for Ethiopian Birr (ETB) against various currencies.

Description
Birr Watch is a lightweight currency converter application that allows users to:

- Convert Ethiopian Birr (ETB) to other currencies

- Add currencies to a personalized watchlist

- View real-time exchange rates

- Store preferences locally in the browser

Features

- Real-time currency conversion: Convert ETB to multiple world currencies

- Watchlist functionality: Track your favorite currencies

- Persistent storage: Automatically saves your watchlist and preferences

- Responsive design: Clean and user-friendly interface
